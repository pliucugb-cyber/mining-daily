矿业日报 · 设计系统规范 v1

2026-09-08 · 目标：信息密度优先，同时保留留白呼吸感 · 适用于 index.html（PWA 静态页）

一、设计原则

密度优先

一屏能看更多条。行高收紧到 1.6，元信息单行并排，取消冗余装饰。

留白留够

卡片内 16px、卡间距 16px、区块间距 32px。留白靠统一间距，不靠随机放大。

一切走 token

禁止手写数值。颜色 24 个、字号 6 级、圆角 3 级、间距 6 档。

禁止 11.5 / 12.5 / 13.5 这类半像素级字号——它们在 Windows 渲染下会发虚，也是"看着不精致"的主因之一。

六、落地计划

步骤动作风险
1. 注入 token在 :root 与 body.dark 下定义全部变量，不改任何选择器无
2. 替换硬编码按映射表把颜色/字号/圆角/间距替换为变量；不改 HTML 结构、不改 class 名低
3. 组件统一卡片、区块头、徽章、价格行、按钮按规范重写样式中
4. 价格区重构16 张大卡 → 紧凑表格式（2~3 列），仅改 CSS 布局中

硬约束（不可破坏）

  • class="section" id="todaySection / archiveSection / rightsSection" 三个锚点字符串原样保留，否则每日生成脚本切分失败。
  • 会展 IIFE（EXPO_WORDS / window.__expoIsExpo / #expoMini）、热榜 #hotListSection、矿权 .rights-list/.rights-row 相关选择器不得改名。
  • 改完必须 bump build-version 与 sw.js 的 CACHE_NAME，否则同事端被 PWA 旧缓存挡住。
  • 改完跑 test_smoke_0908.js（jsdom 25 项）+ preflight_check.py，再 deploy_pages.py。
