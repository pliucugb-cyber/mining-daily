# 移动端系统性优化设计文档（mining-daily）

> 状态：设计稿 v1，待评审（**未执行任何代码改动**）
> 范围：移动端视觉语言 + 交互现代化，令牌驱动，零逻辑改动，遵守 §35 红线
> 依据：REFERENCE.md §35（四轮演进沉淀）、当前 `index.html` `:root` 令牌与移动端组件实测

---

## 0. 目标与原则

- **架构不动、视觉重生**：仅改 `:root` 令牌 + 移动端组件 CSS/结构，绝不碰 `app.js` 业务逻辑与 §35 红线。
- **从"扁平冷灰"到"干净有呼吸感的现代编辑风"**：更大字号、更大圆角、中性干净阴影、内容优先卡片、图标化底栏。
- **可验证**：每个改动都能用现有 batch 203 测试 + 新增/修正断言回归。

## 1. 设计方向对比

| 维度 | 现状（早年风） | 目标（现代风） |
|---|---|---|
| 正文字号 | 13px，偏挤 | 15px 主档，可读性优先 |
| 字阶 | 24/20/16/14/13/12/10，跳跃弱 | 28/22/17/15/15/13/11，层级清晰 |
| 圆角 | 4/8/12px | 6/10/16/20px + 胶囊 |
| 阴影 | 蓝调极弱 `rgba(0,55,112,.06~.08)` | 中性多层、更干净 |
| 头部 | 实色深蓝块 `#1a3a5c` | 浅色 + 搜索药丸（见决策点①） |
| 卡片 | 白底+1px线+弱阴影列表感 | 16/20px 圆角、内容分层、轻强调 |
| 底栏 | 纯文字+3px 下划线 | 图标+文字、激活品牌色（§35.2） |
| 空态 | `.empty-art` SVG（已有） | 保留并精修 |

品牌色 `#0e7490` 与浅蓝 `#38bdf8` **保留**，仅调整用法与配套灰阶。

## 3. 各屏规范

### 3.1 首页（推荐/热榜/往期/会议）
- **头部 `#mdTop`**：由实色深蓝块改为浅色表面（白/极浅），左侧"矿业日报"字标（display 28/700）+ 右侧搜索入口；搜索药丸 `height 44px`、`--r-pill`、占位"搜索矿种、新闻"。
- **分类胶囊**：`推荐/热榜/往期/会议` 改为 `--r-pill` 胶囊；激活态 `--chip-bg` 底 + `--chip-ink` 字（替代现"文字+3px 下划线"）。
- **新闻卡片 `.news-item`（移动端 `@media(max-width:1100px)`）**：`--r-lg/--r-xl`、padding `--s4`、1px `--line-2` 或 `--shadow-sm`；顶部分类 chip（`--chip-bg`）；标题 `--fs-h3`/500 `--ink-900`；来源·时间 meta `--fs-meta` `--ink-300`；按压反馈 `background:--surface-2` + `transform:scale(.99)`。
- **首屏**：保留 sticky 隐藏/显示逻辑（`body.md-top-hidden`），动效 `--dur`。

### 3.2 底栏 `#mobileTabBar`（§35.2 红线）
- 高度 `56px` + 安全区；4 tab **图标+文字**，图标 ~22px，文字 `--fs-nano` 11px。
- **激活态**：图标+文字 `--brand`、底部 20px×3px 品牌色胶囊指示（`--r-pill`）；或激活图标加 `--brand-soft` 圆角底（见决策点②）。
- **AI搜非激活**：图标+文字 `--ink-300` 中性灰（红线：不得回退恒亮）。
- 触控热区 ≥44px，移除 `-webkit-tap-highlight-color`。

### 3.3 「我的」面板 `#mineSheet`
- 全屏 sheet，滑入动效 `translateX(100%→0)` `--dur-slow` `--ease`（保留 `body.md-mine-open` 隐藏其余逻辑）。
- **资料卡**：头像圆（44px `--brand` 底）+ 姓名 `--fs-h2`/600 + 部门 `--fs-meta` `--ink-300`。
- **功能列表**：`我的收藏 ★ / 浏览记录 🕘(+条数徽标) / 深色模式(开关) / 安装到主屏幕 / 关于`；行高 52px、`--r-lg`、图标圆 40px `--brand-soft`、标签 `--fs-body`、右chevron。
- **§35.4② 主题行当前态 ✓**：深色模式行右侧改"开关 + 当前态文字（浅色/深色）"，激活态加 ✓ 标记，明确当前主题。
- 行按压：`--surface-2`。

### 3.4 收藏 / 浏览记录沉浸式（§35.2/§35.3 红线贯穿）
- **返回条 `.favview-bar`**：sticky 顶、`--shadow-sm`；‹ 返回（品牌色）、标题 `--fs-h2`/700、`清空`（`data-act="clear-history"`，**仅 history 模式**显隐，fav 不得出现）。
- **时间分组**：`今天 / 昨天 / 更早`；**§35.4①** 收藏/历史存储加 `ts`（ISO 时间戳），`_parseItemDate`/`_dayBucketOf` 升级按 `ts` 分桶，消除 `mm-dd` 无年份的跨年边界偏差。
- **条目**：卡片 `--r-lg`、标题 `--fs-h3`/500、meta `--fs-meta`/--ink-300、`×` 移除按钮**移动端常驻可见**（§35.2），桌面 hover 显隐。
- **空态 `.empty-art`**：保留插画 SVG（§26），精修描边/配色，引导按钮"去首页看看"复用 `fav-back`。

### 3.5 空态通用
- 所有空态统一 `.empty-art`（128×128）插画 + `.empty-title` + `.empty-tip` + `.empty-cta`，**禁止回退 emoji**（§35.2/§35.3）。

## 4. 交互与动效细则
- **面板/视图切换**：`#mineSheet` 右滑入；`fav/history` 进入用淡入+轻微上移（`--dur`）。
- **卡片按压**：移动端 `:active` 背景 `--surface-2` + `scale(.99)`；桌面 hover `translateY(-2px)` + `--shadow-md`。
- **左边缘右滑返回**（已有）：与 ‹ 返回一致（从"我的"进入 → 回"我的"面板），逻辑不动。
- **清空二次确认**（已有）：`confirming` 态红底 + 呼吸动画，3s 超时恢复；保留 8s 撤销 `mdUndoToast`。
- **骨架/加载**：可选首屏骨架屏（轻量，后续轮），本轮不强制。
- **无障碍**：所有动效 `prefers-reduced-motion: reduce` 降级为瞬时。

## 8. 执行顺序与风险
1. 先改 `:root` 令牌（A）——纯变量，风险最低，全局生效。
2. 再改移动端组件 CSS（B/C/D/E）+ 暗色覆盖（G）。

5. 跑 batch 203 + `mobile_ux_batch` 等，确认零失败；线上字节经本地 gh-pages 副本核验。

**风险**：超大单文件（index.html ~39.8万行、app.js ~32万行），批量文本替换须用字节级单进程脚本 + 唯一性断言 + 写回校验（参照 `single-file-crlf-safe-edit` 约定），禁止并行 Edit 同一文件。
