二、遗漏的重要信息源（10个）

以下按优先级排序。P1=必加 P2=强烈建议 P3=建议 P4=可选

1中国矿业报 P1 必加

URL：http://www.zgkyb.com/

身份：自然资源部中国地质调查局主管主办的行业报，"矿业界"融媒体平台

为什么必加：

  • 矿业行业唯一权威行业报，覆盖政策解读、找矿成果、矿权交易、国际矿业、培训信息全链条
  • 每年发布《全球矿业发展报告》，这是行业内最权威的年度矿业综述
  • 独家信息源：政府工作报告地矿看点解读、两会矿业前瞻、部委政策第一时间解读
  • 数字报+微信公众号+矿业界平台全渠道，内容质量远超普通新闻聚合网站
  • 可以替代死掉的 drc.cgs.gov.cn，而且信息量更大更全

建议关键词：找矿突破、矿产资源法、战略性矿产、增储上产、绿色矿山、智能矿山、全球矿业发展报告、矿业大会

2巨潮资讯网（上市公司公告） P1 必加

URL：https://www.cninfo.com.cn/ （需定向搜索"采矿权""探矿权"关键词）

身份：证监会指定信息披露平台，所有A股上市公司公告发布渠道

为什么必加：

  • 上市矿企的采矿权获取/延续/变更公告第一时间发布于此——比政府矿业权市场更早
  • 搜索结果实锤：大中矿业铁矿探矿权公告、赤峰黄金采矿许可证公告、盛达资源银矿采矿权延续、科力远锂矿出让收益协议——全部首发在巨潮
  • 这些信息直接反映企业层面的矿权动态，是"矿权交易"板块最有价值的增量
  • 可通过"采矿权""探矿权""矿业权出让""资源储量"等关键词定向检索

⚠️ 技术提示：cninfo.com.cn 信息量巨大，不能全量抓取首页，需用WebFetch+特定关键词检索的方式提取矿业相关公告

3重点省份自然资源厅（省级矿权公告） P1 必加

为什么必加：

  • 许多探矿权出让公告发布在省级平台而非国家级——ky.mnr.gov.cn 只汇总部分
  • 搜索确认：内蒙古（铁矿）、云南（磷矿）、四川（磷矿/矿盐）、贵州（金矿）等均有独立省级公告
  • 矿业大省的省级公告比国家级更早、更详细

三、关键词规则缺口分析

缺口1：AI找矿 / 智能矿山 — 完全缺失

这是当前矿业最热的话题之一，但现有10个网站的关键词规则中没有覆盖。

建议新增关键词：AI找矿、智能矿山、智慧矿山、AI综采、无人矿卡、机器学习找矿、地质大数据、数字孪生矿山、AI+地学、葱岭智寻

信息源佐证：新华网报道喀交会AI找矿展示、Mining.com"当机器学会挖矿"专题、四川/内蒙古AI找矿平台落地新闻

缺口2：绿色矿山 / 生态修复 — 仅在排除词中提及

现有规则将"环保"放在排除词中，但"绿色矿山"是政策硬约束，不应排除。

建议新增关键词：绿色矿山、绿色勘查、充填采矿法、尾矿库安全、尾矿库在线监测、矿山生态修复、历史遗留矿山修复、无废矿山、三率指标

建议调整：将"环保治理（冶炼端）"排除词保留，但单独加入"绿色矿山评价""充填法"等正面关键词

缺口3：稀土 / 关键矿产 / 出口管制 — 完全缺失

稀土出口管制是当前地缘政治焦点，总量调控办法刚施行。

建议新增关键词：稀土总量调控、稀土出口管制、关键矿产、战略性矿产、镓锗出口管制、两用物项、矿产供应链安全、资源民族主义、非洲锁矿

缺口4：矿山安全监管 — 完全缺失

中办国办加强矿山安全生产意见、重大事故隐患判定标准扩容等均为重大政策。

建议新增关键词：矿山安全法、重大事故隐患判定标准、非煤矿山执法案例、矿山智能化标准体系、机器人替代率、带班下井

建议新增排除词：煤矿瓦斯（如果你们不关注煤矿安全）
