# mining-daily 依赖清单
#
# ✅ 核心流程【零第三方依赖】—— 仅 Python 标准库
#
#   所有生产脚本（fetch_news / fetch_lme / fetch_price_history / deploy_pages /
#   generate_common / preflight_check 等）均只使用 urllib / json / re / xml.etree /
#   gzip / ssl / hashlib / datetime / os / sys / argparse / threading / queue 等
#   标准库模块，不引入任何 pip 包。
#
#   这是刻意设计：每天 06:15 的 GitHub Actions 定时任务在裸 ubuntu-latest 上跑，
#   不需要 pip install 环节，减少一条失败链路。
#
# 历史：requests 曾被 batch_check_embed.py（一次性外链探测脚本）用到，
# 该脚本已于 2026-09-13 归档至 archive/analysis/，此文件不再需要声明任何依赖。
#
# Python 版本建议：3.8+（CI 使用 ubuntu-latest 默认版）
# 本地模块：source_whitelist / fetch_news / logutil 等均为同仓库 .py，不是 PyPI 包。
#
# 应急回退：设环境变量 MINING_LOG_PLAIN=1 可去掉 logutil 时间戳前缀。
